## What's Changed

### ✨ New Features
- Added a probe auto-loader that picks up and puts down the probe holder automatically, checks that the probe loaded correctly, and moves the machine safely out of the loading area when done
- Added fork settings for setting up the probe holder pickup and put-down
- Added a legend button to the interface

### 🐛 Bug Fixes
- Tools that are not assigned to a slot now use their own offsets
